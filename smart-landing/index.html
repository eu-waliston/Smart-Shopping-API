Tudo que sua lista precisa

Da autenticação à geolocalização de promoções, a Smart Shopping API entrega recursos prontos para integração.

Autenticação JWT

Cadastro seguro, login e rotas protegidas com tokens JWT e senhas criptografadas com bcrypt.

Listas inteligentes

Crie, gerencie e marque itens. Adicione produtos e organize suas compras de forma simples.

Geolocalização

Busque mercados próximos, promoções por distância e ordenação geográfica com latitude e longitude.

Endpoints principais

Rotas essenciais para integrar sua aplicação.

Auth

  • POST /login

Users

  • POST /users
  • GET /users

Shopping Lists

  • POST /shopping-lists
  • GET /shopping-lists

Markets

  • POST /markets
  • GET /markets

Promotions

  • POST /promotions
  • GET /promotions
  • GET /promotions/category/:category
  • GET /promotions/nearby
Setup rápido

Comece em minutos

Clone o repositório, configure o banco e rode as migrations. Documentação Swagger disponível em /api-docs.

# clonar projeto git clone https://github.com/seu-usuario/smart-shopping-api.git # configurar .env DATABASE_URL=postgresql://usuario:senha@localhost:5432/smart_shopping JWT_SECRET="supersecretjwt" # rodar migrations npx prisma migrate dev # iniciar aplicação npm run dev
